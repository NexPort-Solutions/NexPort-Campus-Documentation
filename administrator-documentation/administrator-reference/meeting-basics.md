# Meeting Basics (Admin)

Use the Meeting tab to configure presenter and access join links.

Presenter
- Select the event presenter using the search‑enabled dropdown.
- Results are server‑filtered and paginated.

Join Links
- Presenter and attendee join links display when available.
- Links appear close to the event start window.

Notes
- Zoom is the current online meeting provider.
- Legacy “rooms” are not used.
- An NCS server may be required when creating an online meeting.
