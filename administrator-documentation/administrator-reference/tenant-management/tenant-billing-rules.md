# Tenant Billing Rules

Tenant billing rules define which features are included or billable for a
tenant. These rules are applied at the tenant level and inherited by every
organization under the tenant unless a rule scope says otherwise.

## What billing rules control

- Which features are enabled for the tenant.
- Whether a feature is included or billable.
- Whether a rule targets all organizations or a specific set of organizations.

## Typical workflow

1. Open **Tenant Workspace** and select a tenant.
2. Navigate to the **Billing Rules** view.
3. Add or update rules to mark features as included or billable.
4. Save changes and validate entitlements in the **Tenant Features** view.

> Notes
> - Billing rules do not create invoices. Invoices are handled separately under
>   Invoice Management.
