# Tenant Profile

A tenant profile defines the top-level billing context for an organization tree.
It connects organizations to a tenant billing account and provides the anchor
for entitlements, billing rules, and tenant workspace tools.

## When to use tenant profiles

- Create a tenant profile when a new customer or internal business unit needs a
  distinct billing context.
- Update a tenant profile when the root organization or billing ownership
  changes.

## Key concepts

- **Tenant profile**: The billing and entitlement container that owns rules for
  all organizations under it.
- **Root organization**: The top-most organization associated to the tenant.
  This is typically the organization you use to locate the tenant in Manage
  Campus or the Tenant Workspace.

## Typical workflow

1. Open **Tenant Workspace** and locate the tenant by name or root organization.
2. Review the tenant profile and confirm the linked root organization.
3. Update tenant details as needed (billing account, contacts, or identifiers).
4. Save changes and validate that organization dashboards display the tenant
   association.

> Notes
> - Invoice Management remains separate; tenant profiles govern billing context
>   and entitlements, not invoice creation.
