# Tenant Information Card (Organization Dashboard)

When viewing an organization in **Manage Campus**, the organization dashboard
includes a **Tenant Information** card. This card shows which tenant the
organization belongs to and provides a shortcut to the tenant profile.

## What the card shows

- Tenant profile identifier
- Tenant root organization
- Link to open the tenant profile in the Tenant Workspace

## Accessing the tenant profile

1. Open **Manage Campus** and select an organization.
2. Locate the **Tenant Information** card on the organization dashboard.
3. Select **Open Tenant Profile** to navigate to the tenant workspace.
