# Tenant Billing Notifications

Tenant billing notifications alert Billing Managers and SysOps when important
billing events occur, such as blocked invoices.

## Common tenant billing notifications

- **TenantInvoiceBlocked**: Triggered when an invoice is blocked and requires
  manual review.

## Configure notification templates

1. Open **Customization** > **Notifications**.
2. Select the **TenantInvoiceBlocked** template.
3. Review the subject and body content.
4. Save changes and validate the template variables render correctly.
