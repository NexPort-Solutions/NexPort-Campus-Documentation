# Invitations Overview (Admin)

Manage who is invited to an event from the Invitations tab.

What you can do
- Add or remove invitees: users, groups, and subscriptions.
- Search invitees with server‑side filtering; results paginate automatically.
- Resend invitations and monitor worker status messages when processing is queued.

Permissions
- Your role determines whether you can view, add, or remove invitees.
- Some actions may be disabled for read‑only events.

Tips
- Use precise search terms for large organizations.
- If worker/queue processing is busy, actions may take a moment; the UI will reflect progress.
