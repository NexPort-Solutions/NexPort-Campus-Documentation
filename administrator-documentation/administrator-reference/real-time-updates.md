# Real‑Time Updates (Admin)

Events update in real time via the Calendar. If an event changes while you’re editing, you’ll see an external‑update banner.

Options
- Reload event: refreshes the editor with the latest values.
- Continue editing: keeps the current content so you can complete your draft.

Notes
- After Reload, permissions and available actions may change (for example, if the event moved to a different org calendar).
- Banner also appears when edits occur in another tab or by other users.
