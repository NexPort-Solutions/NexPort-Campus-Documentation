# Real‑Time Updates (Student)

The Calendar updates automatically when events change.

While viewing or editing an event, if someone else makes changes, a banner appears:

- Reload event: loads the latest data for the event without leaving the editor.
- Continue editing: keeps your current content; save later to apply your changes.

Notes
- Some changes (like permission or calendar changes) may alter what you can do after reloading.
- If the event moves to a calendar you cannot access, you may lose edit access.
