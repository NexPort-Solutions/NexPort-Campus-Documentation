# NexPort Campus 6.7.10 Release Announcement

NexPort Solutions is pleased to announce **NexPort Campus 6.7.10**, a focused update that improves writing assignment workflows and fixes a key onboarding issue in ticket-based enrollment. This release prioritizes smoother learner progress and more reliable communications for administrators.

***

### 🔑 Key Enhancements in 6.7.10

#### 1. Writing Assignments Auto-Complete on Submission (Automatic Grading Only)

Writing assignments now automatically mark themselves as complete when a learner submits content **if the assignment is set to automatic grading**. Instructor-graded workflows continue to behave as before.

**Benefit for Learners:** Faster progress through learning paths and immediate visibility that their submission is received when automatic grading is enabled. ([Case 230817](https://darwin-global.fogbugz.com/f/cases/230817/))

***

#### 2. Cleaner UI for Auto-Graded Writing Assignments

When a writing assignment is configured for automatic grading, the **“Graded by ...”** text is now hidden to avoid confusion.

**Benefit for Learners:** A clearer interface that matches the automated grading experience. ([Case 231156](https://darwin-global.fogbugz.com/f/cases/231156/))

***

#### 3. Ticket Batch Welcome Letters Now Include Login Details (Template-Dependent)

Welcome letters triggered by ticket batch redemption now correctly include the user’s login and password values **when the welcome letter template includes those variables**, aligning behavior with bulk upload workflows.

**Benefit for Admins:** More reliable onboarding communications and fewer support requests from newly created users (when login/password variables are included). ([Case 231120](https://darwin-global.fogbugz.com/f/cases/231120/))

***

### 🌟 Why This Release Matters

Together, these fixes reduce friction at two critical points in the learner journey: completing assignments and first-time access. The result is clearer feedback for learners and more dependable automation for administrators.
